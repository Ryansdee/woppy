# Rapport : lot 4, espace équipe Woppy (23/10/2026)

Pages concernées : modération, historique de modération, support, statistiques, postes internes, candidatures (liste et détail), enquête de marché. La page de suivi de ticket `/contact/support/[id]` est destinée aux utilisateurs : elle reste hors de l'espace équipe.

## Ce qui change

Toutes les pages passent par un cadre commun, `src/components/staff/StaffShell.tsx` :
- **Contrôle d'accès** : connexion requise, rôle `admin` ou `collaborator`, et `admin` seul pour les pages marquées `adminOnly`. Si l'accès est refusé, la page affiche un écran clair au lieu de rediriger sans explication.
- **En-tête unique** : « Équipe Woppy », titre, description et actions.
- **Navigation** entre les pages de l'équipe, filtrée selon le rôle, et qui défile horizontalement sur mobile.

| Page | Accès | Avant | Après |
|---|---|---|---|
| Modération | équipe | vérifiait le rôle | cadre commun |
| Historique | équipe | vérifiait le rôle | cadre commun |
| Support | équipe | **aucune vérification** | cadre commun |
| Statistiques | équipe | vérifiait le rôle | cadre commun |
| Postes internes | admin | **aucune vérification** | cadre commun |
| Candidatures (liste et détail) | admin | **aucune vérification** | cadre commun |
| Enquête de marché | admin | **aucune vérification** | cadre commun |

Rappel : ce contrôle est côté client. La vraie protection des données reste les règles Firestore, qui ne sont pas dans le dépôt (audit, point 3).
