# Woppy

Stack : Next.js 16 (App Router, `src/app`), React 19, TypeScript, Tailwind 4, Firebase, Stripe. Déployé sur Netlify. Site en français.

Commandes : `npm run dev`, `npm run build`, `npm run lint`.

## Règles
- Comprendre la tâche avant de modifier ; ne lire que les fichiers utiles.
- Changements minimaux, rien de hors sujet.
- Réutiliser les composants, utilitaires et conventions existants.
- Pas de nouvelle dépendance sans justification.
- Vérifier ce qui a été modifié ; signaler clairement les erreurs, ne jamais cacher un test qui échoue.
- Ne jamais toucher aux secrets ni aux variables d'environnement.
- Réponses courtes.
